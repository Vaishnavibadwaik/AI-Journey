
# AI Tic-Tac-Toe Game

An AI-powered Tic-Tac-Toe game developed using Python and Tkinter.

## Features

- Human vs AI gameplay
- Unbeatable AI using Minimax Algorithm
- Alpha-Beta Pruning optimization
- Interactive GUI
- Restart functionality
- Real-time game status

## Technologies Used

- Python
- Tkinter
- Minimax Algorithm
- Alpha-Beta Pruning
- Game Theory

## Project Objective

The objective of this project is to implement an intelligent AI agent capable of making optimal decisions in Tic-Tac-Toe using search algorithms and game theory concepts.

1. Install Python
2. Open terminal in project folder
3. Run:

python main.py
